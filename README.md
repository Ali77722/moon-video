# 🌙 Moon Video — GitHub Edition

فيديو تعليمي عربي متحرك عن خصائص القمر، مبني بالكامل كواجهة HTML/CSS/JavaScript.

## تشغيل الفيديو
افتح `index.html` أو استخدم GitHub Pages.

## إخراج MP4
يوجد workflow في `.github/workflows/render.yml` يقوم بتشغيل Chromium + FFmpeg وإنشاء `moon-video.mp4` كـ GitHub Actions artifact.

## المحتوى
- قطر القمر والمسافة عن الأرض
- مدة دورته حول الأرض
- أطوار القمر
- الجاذبية والغلاف الجوي
- جليد الماء في المناطق القطبية

المراجع العلمية الأساسية: NASA Moon Facts وNASA Lunar Science.
